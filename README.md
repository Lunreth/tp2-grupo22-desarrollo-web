# GLASSMORPHISM — Trabajo Práctico N°2 - Grupo 22

## Descripción

Sitio web grupal desarrollado para **Desarrollo de Sistemas Web · Front End · 2026 · 2° Cuatrimestre**.

El proyecto presenta una portada del equipo, cinco perfiles individuales y una bitácora del proceso de desarrollo.

## Tecnologías
- React 18 para construir la interfaz con componentes.
- Vite 5 como herramienta de desarrollo.
- React Router DOM 6 para la navegación interna.
- JavaScript, HTML y CSS.
- Lucide React para los iconos.
- JSON local para los datos de recursos.
- GitHub para el trabajo colaborativo.
- Vercel para publicar la aplicación.
